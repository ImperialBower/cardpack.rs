# Security Policy

## Supported versions

Only the latest release on [crates.io](https://crates.io/crates/cardpack)
gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub:
<https://github.com/ImperialBower/cardpack.rs/security/advisories/new>

Include what you found, the version, and steps to reproduce it. You will get
a reply as soon as possible. If the report is valid, a fix and a RustSec
advisory follow.
