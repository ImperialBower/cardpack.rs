# What it covers

An aggregated index of open work: EPIC docs and their status, GitHub issues,
and `TODO`/`FIXME` comments found in source. Maintained by the `/backlog`
skill rather than by hand, so it is a **derived** view — the linked sources
are authoritative.

# Caveats

* Items tagged 🤖 are machine-proposed suggestions, not commitments.
* It goes stale between refreshes; check the "last refreshed" line at the top
  before trusting a status. Debt detail lives in
  [technical debt](/references/technical-debt.md).
