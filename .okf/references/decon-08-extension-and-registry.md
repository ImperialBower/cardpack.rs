# What it covers

The domain's **extension surface** — how a consumer defines a brand-new deck
vocabulary using the same public machinery every shipped deck is built from
([DECON-05](/references/decon-05-french-deck-family.md),
[DECON-06](/references/decon-06-tarot-and-skat.md)) and gains full pile,
format, and validation behavior automatically — plus the **administrative
registry** that enumerates the shipped vocabularies.

# The shipped equivalents

[extending decks](/decks/extending-decks.md) is the crate-specific playbook;
[deck catalog](/decks/deck-catalog.md) is the registry's current contents.
